## 1. 设计语言

从两个参考中提炼，全部规则从严执行：

| 要素 | 规定 |
|---|---|
| 底色 | 双色：侧栏淡鼠尾草 `#EDF1DF`，主区纯白 `#FFFFFF` |
| 分隔 | 一律 `0.5px` 细线，颜色 `#E5E7EB`；不用粗边框 |
| 圆角 | 卡片/输入框 `12–16px`；胶囊控件 `999px`；小按钮 `6–8px` |
| 阴影 | 页面内元素**一律无阴影**；仅浮层（下拉菜单）用 `0 8px 24px rgba(0,0,0,.12)` |
| 字号 | 正文 `13–14px`，空状态标题 `22px`，说明文字 `11–12px` |
| 字重 | 只用 `400` 与 `500`，不用 600/700 |
| 大小写 | 中文为主；英文一律句首大写，不用 Title Case |
| 图标 | 线性图标，`14–18px`，继承文字色；能力卡图标用彩色点缀 |
| 间距 | 组件内 `8/12px`，区块间 `14–24px`，留白从宽 |

**禁止**：渐变、毛玻璃、霓虹、装饰性纹理、重投影。参考里没有的东西都不加。

## 2. 布局

三栏，宽度 `180px | 1fr | 280px（可收起）`。

### 2.1 左栏（淡鼠尾草底）

```
DeskMinis ⌄                     ← 应用名 + 下拉（切换工作区，M2）
  ✎ 新建会话
  ⌸ 工作区
  ⚿ 技能                        ← M2 前置灰
  ⧉ 设备                        ← M3 前置灰
最近
  · 重构同步引擎                 ← 当前项底色 rgba(255,255,255,.85)
  · 看下这个报错
  · 整理下载目录
```

- 导航项 hover 底色 `rgba(255,255,255,.65)`，圆角 6px
- 会话项右键菜单：重命名 / 置顶 / 删除（删除走 `confirm:true`）
- 同步来的会话在标题右侧加一枚小设备图标（M3）

### 2.2 中栏

**空状态**（无消息时）：居中「今天做点什么？」+ 2×2 能力卡（最大宽度 380px）
- 读懂这个代码库（望远镜，蓝）→ 填充 `分析一下这个项目的结构`
- 写个功能或脚本（工具，紫）
- 跑命令排查问题（终端，绿）
- 整理本机文件（文件，橙）

点击卡片 = 把示例提示填进输入框（不直接发送，让用户改）。

**对话流**：不用气泡。用户消息右侧浅底、助手消息无底色平铺，靠间距和字色区分。工具卡与权限卡见 §3。

**输入框**（视觉重心）：
```
┌──────────────────────────────────────────────┐
│ 让 DeskMinis 做点什么…                        │
│                                              │
│ ＋  [⌸ 工作区] [⛨ 每次确认]      [Sonnet 5 ⌃] ● │
└──────────────────────────────────────────────┘
```
- 边框 `0.5px`，圆角 14px，聚焦时边框转 `--border-strong`
- 底部工具条三个胶囊选择器 + 右侧圆形发送按钮（深色底、白箭头）
- Enter 发送，Shift+Enter 换行；运行中发送按钮变方形停止键（调 `chat.cancel`）

### 2.3 右栏（可收起，M1 占位）

标签页：终端 / 文件 / 任务。M1 只放占位说明，M2 填实。

## 3. 关键组件

### 3.1 模型选择器（对应 provider 实例）

点击展开浮层，列出 `provider.instances.list` 的每一项：

```
┌─────────────────────────────┐
│ 我的中继        claude-sonnet-5 │ ✓
│ 官方 Anthropic  claude-opus-5   │
│ 本地 Ollama     qwen3           │
├─────────────────────────────┤
│ ✎ 管理模型                    │
└─────────────────────────────┘
```
- 每行：实例名（主）+ 模型 id（次，灰）；当前项右侧打勾
- 无密钥的实例置灰不可选，尾部标「缺密钥」
- 底部「管理模型」进设置（增删改 provider）
- **绝不显示密钥本身**；`hasApiKey` 只用来决定是否置灰

### 3.2 权限选择器（对应权限网关）

```
┌─────────────────────────────┐
│ ⛨ 每次确认      每条命令都问   │ ✓
│ ⛨ 本会话沿用    批准过的不再问 │
│ ⛨ 只读模式      不允许任何写   │
└─────────────────────────────┘
```
- 「每次确认」= 默认，`askOnce`
- 「本会话沿用」= 批准时默认选中 `allow-session`
- 「只读模式」= 写类与危险类一律 `notAllowed`
- 危险命令在任何模式下都硬拦截，选择器里注明

### 3.3 工具调用卡

折叠态：图标 + 模型自报的 `tool_title` + 状态（⏳/✅/❌）+ 展开箭头。
展开态：等宽字体显示参数与输出，最高 200px 后内部滚动。
`file_edit` 展开显示 diff（增行绿底、删行红底）。

### 3.4 权限确认卡

内联在对话流中，琥珀色调（`--bg-warning` 底 + `--border-warning` 边）：
- 标题：请求执行命令 / 请求写入文件 / 请求读取文件
- 命令或路径**逐字显示**（等宽字体，可换行，不截断——用户必须看到完整内容才能判断）
- 三个按钮：仅此次 / 本会话允许 / 拒绝
- 30 秒无响应自动消失（收到 `permission.resolved` 广播时移除）

## 4. 实现约定

- 引入 `src/renderer/src/styles/tokens.css`，把 §1 的值定义为 CSS 自定义属性；组件用变量，不写死颜色
- 淘汰现有内联样式，改用少量语义类（`.pane-left` `.composer` `.tool-card` `.perm-card` 等）
- 暗色模式：M1 不做，但 tokens 分层要为将来留出（颜色全部走变量）
- 组件文件维持现有划分，新增 `ModelPicker.vue`、`PermissionPicker.vue`、`EmptyState.vue`

---

## 5. 不做（留给 M2+）

- 暗色模式切换
- 右栏终端/文件/任务的实际内容
- 会话搜索、拖拽排序
- 技能与设备面板（M2/M3 功能本身尚未实现）
