## 1. 信息架构（IA 先行）

### 1.1 导航模型：一会话 = 一任务，三栏各就各位

```
┌────────────────────────────────────────────────────────────┐
│ TitleBar：窗口控制 + 会话标题 + 全局状态点（同步/主题）        │
├──────────┬──────────────────────────────┬──────────────────┤
│ 左栏      │ 中栏 · 对话流（Codex 式）      │ 右栏 · 任务区     │
│ 任务列表  │  - 回合流（用户/助手/工具/事件）│ （WorkBuddy 式）  │
│ 状态徽标  │  - 内联权限卡                 │ 进度 / 产物 / 文件 │
│ ─────── │  - 输入区                     │ 终端 / 同步状态    │
│ 底部固定：│                              │                  │
│ 设置·设备 │                              │                  │
└──────────┴──────────────────────────────┴──────────────────┘
```

决断（对应审计 IA-1/IA-2/IA-4）：

1. **会话即任务**：左栏列表项从「标题+时间」升级为「任务卡」——标题、相对时间、**状态徽标**（●进行中 / ✓完成 / ✕失败 / ⏸等待批准）、产物计数角标。数据全部已有（chat.running / lastStopReason / toolCards），无需新后端。**【变体 A 定稿（用户 2026-07-31 拍板）】**——任务卡式（状态徽标 + 产物角标，亲和）胜出于紧凑列表式（变体 B：30px 行高 + mono 时间）；双变体对比页保留于 [sidebar.html](file:///c:/Users/24739/Downloads/openminis1/docs/prototypes/mu1/sidebar.html) 作历史记录。
2. **设置独立成页**：从右栏 gear tab 解放，改为左栏底部固定入口 + `Ctrl+,`，打开为**模态设置页**（模型/外观/权限/设备与同步 四个 section）。右栏不再混语义。
3. **设备与同步是一等导航项**：左栏底部与设置并列「设备」入口（M3b/c 落地处，§7）。不进设置深层——同步状态需要一眼可见。
4. **标题栏瘦身**：删掉无 handler 的前进/后退与 noop 菜单项；保留侧栏开关、会话标题；右侧新增**同步状态点**（§7.3）与主题循环键。菜单栏降级为仅 文件/视图/帮助 三组真实可用项。

### 1.2 三栏尺寸与行为

| 栏 | 宽度 | 行为 |
|---|---|---|
| 左栏 | 232px（可收起到 0） | `Ctrl+B`；收起后中栏全宽 |
| 中栏 | 1fr，min 480px | 对话流 max-width 760px 居中（超宽屏不拉宽文本行） |
| 右栏 | **360px**（可拖 320–480，可收起） | 默认宽从 300 提到 360：终端 80 列不再灾难性折行；拖拽分隔条 6px 热区 |

### 1.3 路由与状态归属

- 对话流状态（流式文本/工具卡/权限卡/事件）归中栏；**任务状态（进度/产物/token/水位/同步）归右栏**——审计 H4 的「同一事件双份呈现」由此根治：对话流只留轻量内联事件条，任务面板只留状态卡，各管一段生命周期（进行中看右栏，回溯看对话流）。
- 空状态（EmptyState）升级为**任务起点页**：3 个示例指令卡（读代码/写脚本/跑命令）+ 最近任务 3 条——WorkBuddy 首屏任务模板的克制版。

## 2. 中栏 · 对话流（Codex 式）

### 2.1 回合结构（Turn）

一个回合 = 用户消息 + 助手工作区 + 助手正文。回合间 1px 分隔线 + 24px 间距，回合内块间 8px。

```
╭──────────────────────────────────────────╮
│ 你 · 14:32                          [复制] │  ← 用户消息：无气泡，标签行 + 正文
│ 请把 hello.txt 翻译成大写…               │
├──────────────────────────────────────────┤
│ ✓ 读取 hello.txt          0.3s      [›] │  ← 工具行：单行折叠，默认收起
│ ✓ 写入 hello.txt          0.2s      [›] │
│ ── 已编辑 hello.txt  (+4 / −1) ── [展开] │  ← 编辑类工具：diff 摘要行
│                                          │
│ 完成。文件已改为大写：                    │  ← 助手正文：完整 Markdown
│ ## 结果                                  │
│ `HELLO WORLD` …                          │
╰──────────────────────────────────────────╯
```

与现状的差异（逐条对应审计）：

| 项 | 现状 | v2 |
|---|---|---|
| 用户消息 | 右侧 12% 灰气泡（iOS 不对称） | **无气泡、左对齐**、标签行「你 · 时间」+ hover 复制——Codex 式回合归属 |
| 助手正文 | 纯文本 pre-wrap | **全量 Markdown**（§5.1） |
| 工具调用 | 36px 彩色胶囊 | **单行工具行**：状态符号（✓/✕/⠿）+ 一句人话标题 + 耗时 + 展开 chevron；默认折叠 |
| 编辑结果 | 裸 JSON pre | **diff 摘要行 + 可展开 diff 视图**（§5.4） |
| 事件 | 三种位置三种样式 | **统一事件条组件**（§5.3），一处语法 |

### 2.2 工具行（ToolLine）

- 形态：32px 高单行，图标 14px，标题 13px，耗时 mono 11px 右置；执行中左侧 spinner（⠿ 逐帧或 CSS 旋转 14px 圆环）， shimmer 取消（太吵）。
- 配色：图标常态 `--label-secondary`；完成符号 ✓ 绿、失败 ✕ 红、取消 − 黄；**类型色取消**（绿/青/蓝/橙/紫五色退场——审计 V-5，Codex 常态灰阶 + 状态色的标准）。
- 展开区：参数（mono 12.5px，键名 `--label-secondary`）、输出（mono 12.5px，max 240px 内滚）；file_edit 类型展开区为 diff 视图而非 JSON。
- 连续 3+ 个同类型工具行自动**成组折叠**：「读取 4 个文件 [›]」。

### 2.3 密度与排版（等宽克制）

- 正文 14px / 1.6；标题层级 ≤3 级（h2 16px / h3 14.5px，bold）；列表缩进 20px。
- mono（`--font-mono`）只出现在：代码围栏、行内码、路径、命令、耗时/token 读数。正文与 UI 文案永远比例字体。
- 代码围栏：深色底槽（浅模式 `#F6F6F4` 暖灰底 / 暗模式 `--bg-tertiary`），顶部 24px 槽条（语言名 mono 10.5px + 复制键）；**无语法高亮配色狂欢**——最多关键字/字符串/注释三色，且饱和度压到 40% 以下（对齐 Codex 低饱和）。
- 行内码：mono 13px + `--fill-quaternary` 底 + 4px 圆角 + 1px/3px 内边距。

### 2.4 流式呈现

- 文本增量按**词粒度淡入**：alpha 0→1、0.3s、ease-out，同批交错 ≤0.08s——移植 OpenMinis TextFadeAnimator 的节奏参数（0.45s→0.3s 适配桌面节奏），DOM 层实现（新建 `<span>` 只做 opacity transition，不触发重排）。
- 滚动跟随：贴底跟随；**用户上翻 >40px 即解除跟随**，右下浮出「↓ 回到底部」小圆钮，回底后恢复（治审计 X-2）。

## 3. 视觉系统（令牌层演进）

tokens.css 现有：色彩（iOS 语义）+ 圆角 + 字体族 + 材质。**缺尺度与语义槽位**，组件写死 px。v2 向上长两层，既有色板不动（OpenMinis 皮肤同源）。

### 3.1 新增：尺度令牌（spacing / font-size / line-height / icon）

```css
:root {
  /* 字号尺度（桌面密度基线 14） */
  --fs-display: 17px;   /* 设置页标题 */
  --fs-title:   15px;   /* 面板头、卡片标题 */
  --fs-body:    14px;   /* 正文 */
  --fs-ui:      13px;   /* UI 控件、列表项 */
  --fs-caption: 12px;   /* 辅助说明 */
  --fs-mono:    12.5px; /* 代码/读数 */
  --fs-micro:   11px;   /* 角标、耗时 */

  /* 间距尺度（4 的倍数） */
  --sp-1: 4px;  --sp-2: 8px;  --sp-3: 12px; --sp-4: 16px;
  --sp-5: 20px; --sp-6: 24px; --sp-8: 32px;

  /* 图标尺寸 */ --ico-s: 14px; --ico-m: 16px; --ico-l: 20px;
  /* 控件高 */ --h-control: 32px; --h-input: 36px;
}
```

组件迁移原则：现有写死的 16.5/15/13/12px 全部就近映射到尺度（16.5→14 正文、17→15 标题、13→13、12→12），iOS 直搬字号退场（审计 V-1）。

### 3.2 新增：语义色槽（在既有 iOS 色板之上再抽象一层）

```css
:root {
  /* 表面层级 */
  --surface-0: var(--bg);            /* 应用底 */
  --surface-1: var(--grouped-bg-secondary); /* 卡片 */
  --surface-2: var(--grouped-bg-tertiary);  /* 卡中槽 */
  /* 行动 */
  --action: var(--accent);           /* 唯一主行动色（链接/主按钮/选中） */
  /* 状态（彩色只给状态） */
  --state-ok: var(--green); --state-err: var(--red);
  --state-warn: var(--orange); --state-info: var(--link);
  /* 工具类型色 —— 退役，保留变量名兼容，全部映射回灰阶 */
  --tool-shell: var(--label-secondary); /* …等 */
}
```

**brand 暖灰褐降权**（审计 V-2）：新建按钮改用 `--action` 蓝或中性 `--fill` 底；brand 仅保留在头像底/装饰渐变（assistant-gradient），不再承担主行动色。选中态统一 `--action` 10% 底 + `--action` 文字。

### 3.3 暗色三模式 · 硬约束与验收

机制不变（跟随系统 / 强制浅 / 强制深，`:root[data-theme]` 覆盖，tokens.css 已就绪）。v2 补齐约束：

1. **组件禁止写死颜色**继续是红线；新增：**禁止写死 `color-mix` 的百分比**——evnote 那类 10%/30% 混合比例收进语义槽（`--state-warn-bg` / `--state-warn-border`），三模式下比例可分别调。
2. 任何新组件 PR 必须附**三模式截图**（浅/深/跟随系统在深色系统下），进验收清单。
3. 代码围栏底、diff 红绿、xterm 主题为三模式各定义一份（xterm 主题对象跟随 data-theme 切换）。
4. `color-scheme` 已配；滚动条/选区/表单控件随模式自动正确，不另写覆盖。

## 4. 右栏 · 任务与结果区（WorkBuddy 式）

### 4.1 从「三抽屉」到「任务仪表板」

顶部保持 tab，但语义重排：**进度**（默认）/ **产物** / **文件** / **终端**。设置移出（§1.1-2）。

#### 进度 tab（默认，WorkBuddy 进度可视化）
```
┌─ 本轮任务 ─────────────────────┐
│ ● 正在执行 · 已用 42s           │
│ 翻译 hello.txt 为大写           │
│                                │
│ 步骤                            │
│  ✓ 读取文件            0.3s    │
│  ✓ 写入文件            0.2s    │
│  ⠿ 等待批准 — 执行命令   [去处理]│  ← 亲和短句 + 一键跳转对话流权限卡
│                                │
│ Token  入 3.2k · 出 0.8k       │
│ 上下文 ▓▓▓░░░░░░░ 12% (实时)    │
└────────────────────────────────┘
```
- 标题=会话任务句（亲和短句，非技术原文）；步骤列表与对话流工具行同数据、不同呈现（这里是进度叙事，那里是执行记录——不重复，各看各的）。
- fallback/compacted/offloaded/retry 四事件在此以**状态卡**呈现（沿用 M2d 成果，样式换 WorkBuddy 式圆角卡 + 左侧 3px 色条已有，保留）。
- 「等待批准」状态显著化：进度 tab 标题栏显示橙点，点击 [去处理] 滚动定位到对话流权限卡。

#### 产物 tab（新增，WorkBuddy 产物汇总的克制版）
- 本会话**写/编过的文件**汇总卡：文件类型图标 + 相对路径 + 「+4/−1」增删徽标 + 点击在文件 tab 定位。数据源：toolCards 中 file_write/file_edit 记录，无需新后端。
- 空态：「本轮还没有产物」。

#### 文件 / 终端 tab
- 文件：保留 M2d 树 + 预览，空态补一句引导（「agent 读写过的文件会出现在这里」）。
- 终端：保留 xterm；360px 默认宽 + 拖宽上限 480，80 列可用。

### 4.2 状态反馈亲和度标准

- 所有等待态文案短句化：「等待你的确认」「正在读取 4 个文件」「还差一步就完成了」。
- 技术原文（错误 JSON/堆栈/request id）**永远折叠**：错误卡显示一句人话（「模型服务暂时不可用（503）」）+「详情 [›]」展开原文 +「重试」按钮（治审计 X-5/H4）。

## 5. 组件规格（全局皮肤 = OpenMinis）

### 5.1 Markdown 渲染（最高优先，审计 H1）

- 渲染范围：GFM 子集——标题（h2/h3）、粗/斜/删、行内码、代码围栏（带语言槽+复制）、无序/有序列表、引用块、链接、表格（简单）、分隔线。任务列表与 HTML 不支持。
- 实现取向：renderer 内自研轻量解析（对齐 OpenMinis MinisMarkdownParser 的 AST 思路），**不引重型依赖**；流式走「稳定前缀 + 尾部重解析」——等价于 OpenMinis 的 append-only fast path。
- 风格同源 OpenMinis：正文行高、代码底槽圆角（`--r-control`）、引用块左 3px `--separator` 条、链接 `--action`。
- 用户消息不渲染 Markdown（纯文本 pre-wrap），与 iOS 一致。

### 5.2 权限卡（PermissionCard v2）

- 保留内联非模态（OpenMinis 语义）；补强三点：
  1. **倒计时显形**：30s 改为 **90s**，卡内右上 mono 读秒（`88s`），≤10s 变橙；超时 deny 在对话流留「已超时拒绝」事件条（治审计 H2）。
  2. **风险分级文案**：danger/gated 分色分文案——danger 红盾牌 +「高风险操作」；gated 橙盾牌 +「需要你的批准」；桥类目有专属标题（「请求发送通知」「请求读取剪贴板」…，治审计 H3 的 default 语义丢失）。
  3. **桥命令一卡两段**：shell 入口卡识别桥命令（`minis notify …` 等）时，卡内直接列出「此命令将触发：通知权限」，一次批准同时放行 shell 与桥类目（UI 层合并决策，不碰权限模型纵深）。
- 按钮序：主按钮「允许」（--action 实底）+ 次「本会话允许」+ 文本「拒绝」；预选高亮改为 2px `--action` 边框（现状 1px 太弱）。

### 5.3 事件条（EventNote）· 统一语法

五类事件（retry / fallback / compacted / offloaded / error）**一套组件**：
`[图标] 一句短句 · 详情[›]`，12.5px，圆角 `--r-md`，语义色槽底色。
- 位置唯一：对话流内联（按时间序插入）。
- error 类升级：短句 + 详情折叠 + 重试按钮（§4.2）。
- 任务面板不再重复呈现同一事件（§1.3 分工）。

### 5.4 diff 视图（编辑类工具）

- 形态：文件头槽（相对路径 mono + `+N/−M` 徽标绿/红）+ 行列表：行号（mono 10.5px, `--label-quaternary`）、+ 行绿底 8%、− 行红底 8%、上下文行各 2 行折叠（「⋯ 收起 12 行」）。
- 饱和度：绿/红底在三模式分别调（暗色降 alpha 至 12% 提升可读）。
- 数据源：file_edit 的 old/new 已在工具载荷中，纯前端 diff（LCS 行级），无后端改动。

### 5.5 输入区（Composer v2）

- 自适应长高：1–8 行（36→176px），超过内滚（治审计 X-6）。
- 底部工具行左起：工作区胶囊、权限档位、模型选择（保留 M2c/d 成果）；右端发送键 32px 圆形 `--action` 实底（现为 --label 黑块，色权修正）。
- 附件能力：MU2 只做**图片粘贴/拖拽进会话附件目录**（缩略图 chip 48px 圆角 `--r-control`，对齐 OpenMinis AttachmentChip 语义，功能砍到最小）；语音/`@`引用不进 MU2。
- 斜杠菜单保留；增加 `/` 菜单与技能描述的键盘可达性说明。

### 5.6 设置页（独立模态）

- 左 180px section 导航 + 右内容：模型（ProviderSettings 平移）/ 外观（三模式单选 + 主题随动说明）/ 权限（默认档位 + askTimeout 说明）/ **设备与同步**（§7）。
- 遮罩 40% 黑 + 卡片 720px `--r-sheet`，`Esc` 关闭。

## 6. 与 OpenMinis 的跨端一致性（单列硬约束）

### 6.1 语义必须同构（两端同一组件语义，允许实现差异）

| 组件 | 同构内容 | OpenMinis 参照 |
|---|---|---|

### 6.2 允许平台差异（各自美丽，不求同构）

| 面 | 桌面端 | iOS 端 |
|---|---|---|
| 标题栏/窗口控制 | 自绘 TitleBar + 原生 min/max/close | 系统导航栏 |
| 系统托盘 | 常驻托盘 + 菜单（M2d 成果） | 无此概念 |
| 右栏 | 任务仪表板（360px 可拖） | 无右栏（底部 sheet 呈现文件/任务） |
| 会话列表 | 左栏常驻 + 状态徽标 | 列表页 push/pop |
| 用户消息形态 | 无气泡标签行（宽屏） | 右侧填充气泡（窄屏） |
| 终端 | 内嵌 xterm 全功能 | 无 |
| 快捷键 | Ctrl+B/N/,/ Esc 体系 | 手势体系 |

判定原则一句话：**「同一动作两端语义相同」为同构红线；「同一语义两端形态适配各自平台」为允许差异**。

## 7. M3b/c 前瞻面（现在就要留白）

### 7.1 配对管理（M3a 后端已就绪，前端落地处）

- 入口：左栏底部「设备」→ 设备页（模态或右栏临时 tab，实施期定）。
- 页内容：
  - **已配对设备列表**：设备名、指纹前 12 hex、last seen 相对时间、在线点（绿/灰）；操作=移除。
  - **发起配对**：8 字配对码大字号 mono 展示（32px，字距 8px）+ expiresIn 数据驱动倒计时（M3a 实现为 300s/5 分钟）+ 「等待对端输入…」状态句；完成 → 设备卡滑入列表。
  - **加入配对**：输入框 8 位（mono 大写自动格式化 `XXXX-XXXX`）+ 确认。
- 视觉：WorkBuddy 式亲和（圆角卡 + 状态句），但指纹/配对码用 mono 保技术可信度——本页是两基准的交界，亲和壳 + 可信核。

### 7.2 设备列表（M3b）

- 设备卡增列：角色（本机/对端）、同步范围（会话/记忆/技能）、当前同步态徽标（§7.3）。
- 会话列表项可带**来源设备小标**（对端创建的会话，头像右下角 10px 设备色点）——多设备会话混排时可分辨。

### 7.3 同步状态（M3b）

- **标题栏同步状态点**（全局常驻）：绿=已同步 / 橙脉冲=同步中 / 灰=离线仅本地 / 红=同步冲突。hover 出明细卡（最近同步时间、各设备水位、冲突数）。
- 会话内联事件条新增第六类 `synced`：「已从 iPhone 同步 12 条消息 · 详情[›]」（复用 §5.3 组件，色 `--state-info`）。
- 冲突呈现：marker LWW 对用户不可见；真正需要人判的（同消息双端编辑）以「两个版本」折叠卡呈现——M3b 实施期细化，本文只钉入口与容器。

### 7.4 执行端钉选（M3c）

- 会话级钉选：会话卡右键/长按菜单「在此设备执行 ⌄」→ 列出在线设备（本机默认），选择后会话标题行出现设备 chip。
- 工具行前缀：在对端执行的工具行，图标前加 10px 设备色点（与 §7.2 会话来源点同色）——一条会话跨两端执行时，执行归属一眼可辨。
- 红线（M3 非目标重申）：不做透明跨端 shell 镜像、不做自动就近调度；钉选是显式用户行为。
