# F10A Word 生成、内容核验与覆盖保护

沿用原设计 `work/design/F10A-设计.md`，第二段整合基线为 `92f1997`；三种格式处理器拆分与生成器第一段的字节保持不变。每项一个本地提交；本次由当前代理复核，没有独立审查。

- `office_write` 先规范化与生成，再按最终字节摘要做内容回读；失败不问权限、不写文件，核验代码意外异常如实返回未核验。权限返回后复查取消，唯一写入入口为 F08 `commitFileWrite`。
- 覆盖检查在同步 `produce(before)` 内按当时的原字节判定。拒绝或检查异常走 `abort`，不创建检查点，不修改原件，不自动改路径。成功覆盖可恢复原始字节；重复同内容不增加记录。
- 同步 ZIP 检查验证目录边界、条目数量、ZIP64/多卷/加密/压缩法、重名、解压预算、长度和 CRC。本地头决定数据起点；带数据描述符的条目使用中央目录尺寸。
- DOCX 来源是保守识别：标记或旧版五部件、部件和正文元素白名单；无法确认就拒绝。默认页脚必须与生成器的 PAGE 域相同，避免保留标记但新增页脚文字的脚本编辑丢失。不是文件真实性或任意改动的鉴定：符合受支持子集的文本/属性改动可能仍被允许整份重建；首版没有保真编辑。
- 三种格式成功输出保留路径和摘要首行，加内容核验与版式核验两行；最多二十行提示。产品内版式恒为未核验。Excel/PowerPoint 的生成字节与说明片段保持黄金值，内容核验仍未实现。
- `office_read` 的未提取说明由处理器追加，不进入 `docToText` 或文件对比。来源识别供读写共用；可识别的生成器 PAGE 页脚不误报遗漏，修改过的页脚属于遗漏内容。
- 默认外观、规模和表格宽度边界详见生成器与测试。生成输入未采用字段提示不代表保真读取任意已有文档。

真实 Word 的证据与源码测试分开存档。部件摘要相同才能沿用第一段的真实量测；最终真实运行、重判、渲染页面、自检、许可与平台限制均按实际结果记录在交付说明，不能用 ZIP 回读代替版式验收。
